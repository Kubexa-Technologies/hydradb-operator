CRD upgrade path:
  The CustomResourceDefinitions in charts/hydradb-operator/crds/ are
  install-only. Helm installs them on first install but NEVER upgrades them
  on `helm upgrade` (Helm crds/ semantics). To pick up CRD changes, apply
  the new CRDs explicitly before upgrading the release:

    kubectl apply --server-side -f charts/hydradb-operator/crds/
    helm upgrade <release> charts/hydradb-operator

  The canonical CRD source is `cargo xtask gen-crds` output (deploy/crds/);
  charts/hydradb-operator/crds/ must stay byte-identical to it.
